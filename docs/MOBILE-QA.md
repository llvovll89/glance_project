# 모바일 보완 및 검증 상태

기준일: 2026-10-26

## 반영한 보완
- 모바일 검색창과 테마 선택의 글꼴을 16px로 설정해 iOS의 입력 포커스 확대를 줄임.
- 400px 이하 점검 목록을 한 열로 배치하고 작은 글꼴 대신 13px 사용.
- 주요 동작 버튼은 최소 44-48px 터치 높이.
- 결과 목록과 부품 설명의 intrinsic 최소 폭 해제, 긴 단어 줄바꿈 처리.
- dialog 높이를 동적 뷰포트와 safe-area에 맞추고 내부 스크롤 허용.
- 설명창 열림 동안 배경 페이지 스크롤 잠금, 닫힐 때 이전 값 복원.
- 좁은 화면과 가로 방향의 낮은 화면에서 설명창 높이 제한.
- viewport-fit=cover 및 safe-area 여백.
- 640/1024/1536px WebP와 srcset/sizes로 이미지 전송 최적화.
  원본 PNG 1,850,212 bytes. WebP 각각 17,512 / 38,514 / 75,556 bytes.
- 가로 넘침을 숨기는 overflow-x:hidden은 사용하지 않음.

## 실제 통과한 검사
- npm run build: TypeScript 전체 검사 및 Vite 프로덕션 빌드 통과.
- node verify-design.mjs: 서버 렌더링, 초기 자산 참조, 대비 검사 통과.
- 주요 텍스트/버튼 대비: 라이트 최소 6.02:1, 다크 최소 8.24:1.

## 아직 검증하지 못한 항목
브라우저 도구를 연결하지 못했고, 별도 테스트용 Chrome 실행은 자동 승인 검토에서 거절됨.
사유: 이 세션의 추가 샌드박스 승인이 비활성화됨.
따라서 아래는 CSS 대응을 작성했지만 실제 브라우저에서 통과했다고 주장하지 않음.
- 320 / 375 / 390 / 414 / 768 / 1024px에서 document 가로 넘침 확인
- 메뉴, 증상 선택, 모든 점검 단계와 마지막 지원 버튼
- 학습 화면의 모든 부품 선택과 용어 모달
- 검색 결과 및 결과 없음
- 다크 모드, 200% 글자 확대, 가로 방향
- iOS/Android 실기기, 키보드 및 스크린리더, Lighthouse

## 원본 적용 상태
원본 폴더의 App.tsx 덮어쓰기가 Access denied로 거절되어 원본은 변경하지 못함.
apply-update.cjs는 쓰기 가능한 사용자 세션에서 원본을 백업한 뒤 39개 파일을 적용한다. 별도의 임시 테스트 프로젝트에서 파일 해시 일치와 기존 content.ts 보존을 검증했다. PowerShell .ps1 실행은 시스템 정책상 제한되어 배포본은 설치된 Node.js로 실행하는 .cjs 파일을 제공한다.
스크립트는 폴더 권한이나 실행 정책, 시스템 보안 설정을 변경하지 않는다.
