## 검증 한계

브라우저 E2E는 Chromium의 데스크톱·모바일 에뮬레이션을 확인합니다. 신규 작업 관리자 안내의 320px 화면과 확대 창 키보드 동작을 확인했지만, 모든 화면의 320~1024px 구간·200% 확대·전체 키보드 탐색·스크린리더·iOS·Android 실기기·Lighthouse 검증은 완료하지 못했습니다. 각 OS 수집 명령의 실제 하드웨어 조회 실행도 미검증입니다. 설정 안내 그림은 단순화한 예시이며 Windows 설정을 직접 조작하거나 실제 기기 상태를 읽지 않습니다.
