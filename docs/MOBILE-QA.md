## 검증 한계

브라우저 E2E는 Chromium 에뮬레이션입니다. 주요 화면의 여러 너비와 200% 확대에 상응하는 640 CSS px 재배치를 확인했으며, 실제 브라우저 확대 조작·모든 중간 너비·전체 키보드 경로·스크린리더·iOS·Android 실기기·Lighthouse 검증을 완료한 것은 아닙니다. Windows 실제 기기의 사양 조회를 확인했고 OS별 CI 러너에서도 조회를 검사하지만, CI 가상 환경은 다양한 실제 macOS·Linux 기기와 OS 클립보드 검증을 대신하지 않습니다. 실제 초보자 참여 테스트는 [진행표](USABILITY-TEST.md)를 준비한 상태입니다. 자세한 범위와 수치는 [품질 검증 기록](QUALITY-REPORT.md)을 참고하세요. 설정 안내 그림은 단순화한 예시입니다.
