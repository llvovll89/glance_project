# 모니터와 그래픽카드 학습 범위

확인 기준일: 2026-11-03.

## 콘텐츠

컴퓨터 이해하기에 모니터와 화면 4개, 그래픽카드와 조합 3개를 추가했습니다. 전체 개념은 39개, 퀴즈는 24문제입니다. 새 설명은 전체 검색·분야별 용어 사전·개별 공유 주소에서도 열립니다.

- 60Hz·75Hz·144Hz의 갱신 횟수와 간격, FPS·응답 속도와의 구분
- FHD·QHD·4K 해상도와 LCD·OLED·QLED 표시 방식의 구분
- VRAM과 일반 RAM·공유 GPU 메모리의 구분, RTX 5060 Ti 8GB 사례
- 구형 모니터의 갱신 한계, 해상도별 작업량, 입력·케이블·변환기 조건

각 설명의 공식 자료 링크는 개념과 확인 방법의 근거입니다. 특정 게임의 FPS, 특정 모니터와의 호환성, VRAM 부족 여부를 자동 판정하지 않습니다. 비교표의 조합은 설명용 사례이며 실측 벤치마크가 아닙니다.

## 검증 방법

`npm run verify`는 콘텐츠·관련 개념 참조·비교표 구조·HTTPS 출처와 기존 기능을 확인합니다. Windows 로컬 실행에서는 Git Bash를 PATH 앞에 두어 셸 구문 검사가 WSL 실행 파일을 선택하지 않도록 했습니다.

`npm run build`와 `npm run verify:performance`로 타입과 빌드, 초기 정적 의존성 전체 크기를 확인합니다. 학습 탐색 화면과 설명 창은 해당 기능을 열 때 불러옵니다. 초기 JavaScript는 547,843바이트, gzip 합계는 163,880바이트로 기존 550,000 / 165,000바이트 예산 안입니다.

Playwright 검사는 학습에서 설명 열기, 비교표, 관련 개념 전환, URL·새로고침·뒤로가기, 검색·용어 사전, 320 CSS px의 밝은·어두운 테마 비교표를 다룹니다. 기존 키보드·주소·사양 입력·점검 기록 회귀 검사도 함께 실행합니다. 생성한 스크린샷은 `test-results`에 저장하며 저장소에는 포함하지 않습니다.

Agent Browser로 데스크톱과 390 CSS px 화면을 살펴봤으며, 주사율 설명 창의 axe-core 자동 접근성 검사는 위반 0건이었습니다. 이는 검사 대상 설명 창의 자동 검사 결과이며 모든 접근성 문제의 부재를 보장하지 않습니다.

위 검증은 에이전트와 Chromium 자동화·모바일 에뮬레이션에 해당합니다. 실제 RTX 5060 Ti, 구형 모니터, 케이블 조합, 실물 모바일 기기나 실제 참여자를 대상으로 검증한 결과는 아닙니다. CI의 Windows·macOS·Ubuntu 가상 머신 검사도 해당 하드웨어 조합 검증을 대신하지 않습니다.
