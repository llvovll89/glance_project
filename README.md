# 한눈 컴퓨터 가이드

> 컴퓨터 문제, 한눈에 짚어보세요 (glance_project)

React + Vite + TypeScript + Tailwind CSS로 작성한 한국어 PC 입문 가이드의 첫 소스 버전입니다.

## 실행

Node.js 최신 LTS를 권장합니다. 프로젝트 폴더에서 아래 명령을 실행하세요.

```powershell
npm install
npm run dev
```

배포 빌드는 `npm run build`, 결과 확인은 `npm run preview`입니다.

## 버전 관리

사용자가 최신 버전을 요청하여 초기 package.json에는 안정 배포 태그인 `latest`를 지정했습니다.
이 환경에서는 npm 레지스트리 접근이 EACCES로 차단되어 실제 설치 버전과 호환성을 검증하지 못했습니다.
설치 후 `npm list --depth=0`으로 버전을 확인하고 생성된 package-lock.json을 커밋하세요.
이후 동일한 의존성 설치에는 `npm ci`를 사용하세요. 설치 실패를 피하려고 이전 버전으로 내리지 않았습니다.

## 포함한 흐름

- 증상 가이드 2개: 화면이 나오지 않음 / 시작 시 비프음
- 점검 단계 이동, 해결 표시, 점검 기록 복사
- 가이드와 개념 검색, 검색 결과 없음 안내
- CPU / RAM / SSD / 그래픽카드 / 운영체제 / 터미널과 셸 설명
- 클릭 가능한 부품 구조도
- 시스템 테마 및 수동 테마 선택
- 키보드 접근, 네이티브 모달 대화상자

## 콘텐츠 범위

학습과 기초적인 외부 점검을 돕는 초기 버전이며 하드웨어 고장을 확정하지 않습니다.
모델별 비프 코드 DB, 오디오 인식, 내부 부품 분해 안내, 자동 PC 사양 수집은 구현하지 않았습니다.
Windows 11 기준 메뉴이며 실제 기기에 따라 다를 수 있습니다.
진단 자료는 ASUS 및 Dell 공식 안내를 참고했으며 각 가이드에 출처를 표시했습니다.

## 검증 상태

- npm 의존성 설치: EACCES로 실패
- 빌드 / TypeScript 전체 검사 / 브라우저 QA / Lighthouse: 의존성 미설치로 실행하지 못함
- 외부에 배포하지 않음

추가 확인: 기존 작업공간의 TypeScript를 이용한 TS/TSX 구문 변환 검사 및 JSON 구문 검사 통과.
이는 이 프로젝트의 최신 의존성에 대한 전체 타입 검사나 빌드 성공을 의미하지 않습니다.
