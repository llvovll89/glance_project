# Glance · 한눈 컴퓨터 가이드

> 컴퓨터 문제, 한눈에 짚어보세요 (glance_project)

컴퓨터 입문자를 위한 한국어 증상 점검과 학습 앱입니다. React, Vite, TypeScript, Tailwind CSS를 사용하며 입력창·셀렉트·텍스트 영역은 Mantine 컴포넌트로 통일했습니다.

## 주요 기능

증상 점검 30종, 개념 설명 32종, 용어 사전, 18문제 퀴즈.

- 관찰한 증상에 따른 단계별 외부 점검과 공식 지원 자료
- 인터넷·소리·Wi-Fi 목록·유선 연결·느려짐 가이드에서 확인 결과에 따른 다음 점검 선택
- 선택한 결과 저장·이어하기·변경과 점검 기록 복사에 결과 포함
- Windows 11 네트워크·소리·작업 관리자 안내 그림과 번호별 설명·확대 보기
- 최근 점검의 단계·확인 상태를 이 브라우저에 저장하고 이어하기·삭제
- 해결·미해결 점검 이력 최대 50개 보관, 결과 메모 작성·수정, 복사·개별 삭제·처음부터 재점검
- 검색, 관련 개념 설명, 점검 기록 복사
- 메뉴·가이드·설명의 개별 URL과 링크 복사, 새로고침·뒤로가기·앞으로가기 지원
- 밝은 테마·어두운 테마·시스템 테마
- 직접 입력한 PC 사양을 브라우저에 저장·수정·삭제하고 점검 기록에 포함
- 실제 파일에 접근하지 않는 3개 셸·7개 미션 연습장
- Windows·macOS·Linux 사양 수집 결과를 미리 보고 입력칸에 적용
- 용어 사전의 분야별 검색과 해설을 제공하는 이해도 퀴즈

## 실행

Node.js 24 LTS 환경에서 검증했습니다. 잠금 파일을 사용해 의존성을 설치합니다.

```sh
npm ci
npm run dev -- --port 5173
```

프로덕션 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다.

## 검증

`npm run build`로 타입 검사와 프로덕션 빌드를, `npm run verify`로 프로젝트 검증 스크립트를 실행합니다. 브라우저 가져오기 테스트는 `npx playwright install chromium` 후 `npm run test:e2e`로 실행합니다. 전체 검증 범위와 모바일 확인 상태는 [모바일 QA 문서](docs/MOBILE-QA.md)를 참고하세요.

`main` 대상 PR과 `main` 푸시에서는 GitHub Actions가 Windows와 Node.js 24에서 의존성을 설치하고 검증·빌드 및 Chromium 브라우저 E2E 테스트를 실행합니다. 증상 목록의 6개씩 확장·접기 및 분야 변경 동작도 `npm run verify`에 포함됩니다. `main` 브랜치 보호 규칙은 `test-and-build` 통과를 병합 조건으로 요구합니다. Vercel Git 연동은 PR에 미리보기 배포를 만들고 `main` 병합 후 프로덕션 배포를 수행합니다.

## 안내 범위

개별 가이드는 `/?guide=network`, 학습 메뉴는 `/?view=learn`, 용어 사전·퀴즈는 `/?view=learn&mode=dictionary`와 `/?view=learn&mode=quiz`, 설명은 `/?view=learn&topic=cpu`처럼 열 수 있습니다. 검색어도 `q` 매개변수로 유지합니다. 쿼리 기반 주소를 사용하므로 정적 호스팅에서도 별도의 경로 재작성 설정 없이 직접 열립니다. 공유 링크에는 점검 메모나 PC 사양을 포함하지 않으며, 진행 상태는 해당 브라우저에 저장된 값이 있을 때만 복원합니다.

Windows PC의 기초 학습과 외부 점검을 안내하며 고장을 확정하지 않습니다. 기기별 절차는 정확한 모델의 공식 설명서를 우선합니다. 분해나 부품 교체를 안내하지 않습니다.

사양 기록, 최근 점검 한 건의 진행 상태와 점검 이력은 해당 주소의 브라우저 저장소에 보관하며 자동 동기화되지 않습니다. 해결 또는 미해결로 기록하면 점검 당시의 증상·확인 단계·선택 결과·입력한 사양·메모를 이력에 남기고 해당 점검의 진행 상태를 지웁니다. 이력 저장 실패 시 진행 상태를 유지하고 재시도·복사를 안내합니다. 진행 상태의 ‘기록 삭제’는 이미 남긴 이력을 지우지 않습니다. 이력은 최대 50개이며 개별 삭제할 수 있고, 사이트 데이터를 지우면 모두 사라집니다. 사양을 나중에 수정하거나 삭제해도 이전 이력에 보관한 당시 사양은 유지됩니다. 가상 명령어 연습장은 일부 문법과 출력을 재현하는 교육용 환경입니다.

사양 가져오기는 Windows PowerShell·CMD, macOS Terminal, Linux bash에서 사용자가 명령을 실행한 뒤 결과를 미리 보고 적용하는 방식입니다. CMD는 PowerShell을 호출하며, 줄바꿈을 보존하기 위해 명령을 UTF-16으로 인코딩합니다. 원본 PowerShell 스크립트는 앱의 명령 보기에서 확인할 수 있습니다. 성공 메시지가 나오면 클립보드에 복사된 상태이므로 앱의 **클립보드에서 가져오기**를 누르거나 직접 붙여넣으세요. 웹페이지가 CPU·RAM 등 실제 사양을 직접 자동 감지하는 기능은 아닙니다. 클립보드 접근이 차단되거나 Linux에 클립보드 도구가 없으면 터미널에 표시된 결과를 직접 복사할 수 있습니다. 수집 명령의 실제 하드웨어 조회는 아직 실행 검증하지 못했습니다.
