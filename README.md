# Glance · 한눈 컴퓨터 가이드

> 컴퓨터 문제, 한눈에 짚어보세요 (glance_project)

컴퓨터 입문자를 위한 한국어 증상 점검과 학습 앱입니다. React, Vite, TypeScript, Tailwind CSS를 사용하며 입력창·셀렉트·텍스트 영역은 Mantine 컴포넌트로 통일했습니다.

## 주요 기능

증상 점검 30종, 개념 설명 32종, 용어 사전, 18문제 퀴즈.

- 관찰한 증상에 따른 단계별 외부 점검과 공식 지원 자료
- 검색, 관련 개념 설명, 점검 기록 복사
- 밝은 테마·어두운 테마·시스템 테마
- 직접 입력한 PC 사양을 브라우저에 저장·수정·삭제하고 점검 기록에 포함
- 실제 파일에 접근하지 않는 3개 셸·7개 미션 연습장
- Windows 사양 수집 결과를 미리 보고 입력칸에 적용
- 용어 사전의 분야별 검색과 해설을 제공하는 이해도 퀴즈

## 실행

Node.js 24 LTS 환경에서 검증했습니다. 잠금 파일을 사용해 의존성을 설치합니다.

```sh
npm ci
npm run dev -- --port 5173
```

프로덕션 빌드는 `npm run build`, 빌드 미리보기는 `npm run preview`입니다.

## 검증

`npm run build`로 타입 검사와 프로덕션 빌드를, `npm run verify`로 프로젝트 검증 스크립트를 실행합니다. 전체 검증 범위와 모바일 확인 상태는 [모바일 QA 문서](docs/MOBILE-QA.md)를 참고하세요.

`main` 대상 PR과 `main` 푸시에서는 GitHub Actions가 Windows와 Node.js 24에서 의존성을 설치하고 검증·빌드를 실행합니다. 증상 목록의 6개씩 확장·접기 및 분야 변경 동작도 `npm run verify`에 포함됩니다. `main` 브랜치 보호 규칙은 `test-and-build` 통과를 병합 조건으로 요구합니다. Vercel Git 연동은 PR에 미리보기 배포를 만들고 `main` 병합 후 프로덕션 배포를 수행합니다.

## 안내 범위

Windows PC의 기초 학습과 외부 점검을 안내하며 고장을 확정하지 않습니다. 기기별 절차는 정확한 모델의 공식 설명서를 우선합니다. 분해나 부품 교체를 안내하지 않습니다.

사양 기록은 해당 주소의 브라우저 저장소에 보관하며 자동 동기화되지 않습니다. 가상 명령어 연습장은 일부 문법과 출력을 재현하는 교육용 환경입니다.

Windows 사양 가져오기는 사용자가 PowerShell에서 조회 명령을 실행한 후 결과를 붙여넣는 방식입니다. 웹페이지가 CPU·RAM 등 실제 사양을 직접 자동 감지하는 기능은 아닙니다. 수집 명령의 실제 하드웨어 조회는 아직 실행 검증하지 못했습니다.
